# Lucid Triton RAW to PPM/PGM Converter

Lucid Tritonカメラから出力されるRAW形式（Bayer配列）のバイナリデータを、汎用的な画像フォーマットである **PPM (Portable Pixmap)** または **PGM (Portable Gray Map)** に変換するためのシンプルなPythonツールです。

## 概要

Lucid Tritonなどの産業用カメラで保存したRAWデータは、ヘッダー情報を持たない純粋なバイナリデータであるため、そのままでは一般的なビューアで開くことができません。本プログラムは、ユーザーが指定した解像度とビット深度に基づいてデータを解釈し、画像ファイルとして書き出します。

### サポートしている出力形式
- **PGM (.pgm)**: 
  - Bayer配列をそのままグレースケールとして保存します。
  - 結果として、画像に格子状のモザイク模様が現れます（RAWデータの正しさを確認するのに適しています）。
- **PPM (.ppm)**:
  - 各ピクセルをRGB形式で保存します。
  - デフォルトでは簡易的な変換（R=G=B）を行いますが、必要に応じてデモザイク処理を追加してカラー化することが可能です。

## セットアップ

### 依存ライブラリ
本プログラムは `numpy` を使用しています。以下のコマンドでインストールしてください。

```bash
pip install numpy
```

※ カラー画像として保存したい場合や、OpenCVによる高度な変換を行う場合は `opencv-python` のインストールを推奨します。
```bash
pip install opencv-python
```

## 使い方

### 1. 設定の変更
プログラム内の「設定項目」セクションを、使用しているカメラの設定に合わせて書き換えてください。

```python
# --- 設定項目 ---
INPUT_RAW = "capture.raw"    # 読み込むRAWファイルのパス
OUTPUT_PGM = "result.pgm"    # 保存するファイル名 (.pgm または .ppm)
WIDTH = 1920                 # カメラの解像度（横）
HEIGHT = 1080                # カメラの解像度（縦）
BIT_DEPTH = 8                # ビット深度 (8, 10, 12 など)
```

### 2. プログラムの実行
ターミナルまたはコマンドプロンプトから実行します。

```bash
python convert_raw.py
```

## 詳細仕様

### ビット深度（Bit Depth）について
- **8-bit**: `uint8` として読み込み、そのまま保存します。
- **10/12-bit**: `uint16` として読み込みます。PPM/PGMの標準的な形式に合わせるため、プログラム内部で 8-bit (0-255) へ正規化（スケーリング）処理を行います。

### RAWデータの構造
本ツールは以下の前提で動作します：
- データはピクセルが横方向に連続して並んでいること。
- ファイルにメタデータやヘッダーが含まれておらず、純粋なピクセル値のみであること。

## 注意事項
- **デモザイク処理**: 本プログラムのPPM出力は簡易的なものです。正確なカラー再現（Bayer $\rightarrow$ RGB変換）を行いたい場合は、OpenCVの `cv2.cvtColor(image, cv2.COLOR_BayerRG2RGB)` 等を使用してください。
- **メモリ制限**: 非常に巨大なRAWファイルを処理する場合、一度にメモリへ読み込むため、RAM容量にご注意ください。
