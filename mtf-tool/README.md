# MTF Measurement Tool (Slanted Edge Method)
## MTF測定ツール（傾斜エッジ法）

このツールは、画像の「エッジ（境界線）」のボケ具合を解析し、レンズやセンサーの解像性能を示す指標である **MTF (Modulation Transfer Function: 変調伝達関数)** を算出するためのPythonスクリプトです。

業界標準の**傾斜エッジ法 (Slanted Edge Method)** に基づいて実装されており、画像内のわずかに傾いたエッジを解析することで、空間周波数ごとのコントラスト維持率を可視化します。

## 🛠 機能
- **ESF (Edge Spread Function)** の抽出
- **LSF (Line Spread Function)** への変換（微分）
- **MTF曲線** の算出（フーリエ変換）
- 正規化された周波数に対するMTF値のグラフ出力

## 🚀 使い方（GIMPとの連携ワークフロー）

このツールは単体で動作しますが、解析精度の向上のため、**GIMPなどの画像編集ソフトで解析領域を適切に切り出して使用すること**を強く推奨します。

### Step 1: GIMPでの前処理
1. **画像の読み込み**: 解像度チャート（ISO 12233など）の撮影画像をGIMPで開きます。
2. **エッジ領域のクロップ**:
   - 解析したい「傾斜エッジ」部分を**正方形に近い形**で切り抜いてください。
   - **重要**: エッジは完全に垂直・水平ではなく、**わずかに（数度）傾いている必要**があります。これによりサブピクセル精度のサンプリングが可能になります。
3. **書き出し**: 
   - `ファイル` $\rightarrow$ `名前を付けてエクスポート` で `edge_sample.png` として保存してください。
   - ※画質劣化を防ぐため、JPEGではなく **PNGまたはTIFF** 形式を推奨します。

### Step 2: ツールの実行
1. スクリプト内のファイルパスが正しいか確認します。
   ```python
   image_file = 'edge_sample.png' 
   ```
2. スクリプトを実行します。
   ```bash
   python mtf_tool.py
   ```

### Step 3: 結果の確認
実行後、matplotlibによるグラフが表示されます。
- **X軸**: 正規化周波数 (Normalized Frequency)
- **Y軸**: 変調伝達率 (Modulation Transfer / Contrast)
- グラフが右側（高周波域）まで高く維持されているほど、解像度が高いことを意味します。

## 📐 技術的な仕組み

本ツールは以下のプロセスで計算を行っています。

1. **ESF $\rightarrow$ LSF**: エッジを横切る輝度変化（Edge Spread Function）を抽出し、それを微分することで、点光源の広がりを示す Line Spread Function を得ます。
2. **LSF $\rightarrow$ MTF**: LSFに対して高速フーリエ変換 (FFT) を適用し、その絶対値を取ることで、空間周波数ごとのコントラスト維持率（MTF）を算出します。
3. **正規化**: 最大値を1.0として正規化し、比較可能な形式で出力します。

## ⚠️ 注意事項
- **ノイズの影響**: 画像に強いノイズがある場合、高周波域の数値が不安定になることがあります。必要に応じてGIMP側で軽いノイズ除去を行ってください。
- **エッジの傾き**: エッジが完全に垂直な場合、サンプリング点数が不足し、正確なMTFが得られません。必ずわずかに傾いたエッジを使用してください。
